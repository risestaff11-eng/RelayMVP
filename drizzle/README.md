# Правила миграций D1

Миграции — это неизменяемая история схемы и данных production. Уже созданные SQL-файлы не редактируют и не удаляют: D1 отслеживает их применение.

Новые миграции не должны содержать:

- `DELETE` или `UPDATE` без точного условия, способные затронуть все строки;
- личные email, телефоны, имена, ключи или другие персональные данные;
- разовые бонусы, тестовые сбросы и подготовку демо-аккаунтов.

Разовые операции с данными выполняются отдельным защищённым скриптом вне Git, после резервного копирования и отдельного согласования.
